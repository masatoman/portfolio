Claude Code v2.1.236 — ANTHROPIC_DEFAULT_MODEL + notify_when_idle (2026-08-19 20:02)

ANTHROPIC_DEFAULT_MODEL 環境変数が追加された。.env や ~/.profile に ANTHROPIC_DEFAULT_MODEL=claude-sonnet-4-6 を 1 行書くだけで、新規セッション起動のたびにモデルを選ぶ操作がゼロになる。routine が毎回 sonnet-4-6 で動く場合、この変数を入れれば設定確認の手間が消える。

クロスセッション SendMessage に notify_when_idle オプションが追加。エージェントが idle になった瞬間に別セッションへ通知を送れる。routine → 別セッション → 成果物確認、のチェーンを組む時に直接使える構造。その他: macOS サンドボックスのワイルドカード read-deny ルール優先度改善 / フルスクリーンレンダラー永続失敗の修正 / /model ピッカー表示高さ最適化。

🟢 即使う — ~/.profile に 1 行追加するだけ。routine 毎日起動のモデル選択ゼロ化 + 将来の routine 連携設計（tooling-feed → content-executor 通知）に notify_when_idle が直接使える。今すぐ入れる価値あり。
