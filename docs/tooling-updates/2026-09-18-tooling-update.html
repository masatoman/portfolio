Claude Code v2.1.275 2026-09-17 22:33 UTC

claude.ai アカウントで設定したスキル・プラグインがターミナルセッションに自動同期されるようになった。 これまで Web UI とターミナルで別々に管理していたスキルを一元管理できる。 さらに Ctrl+Enter（send-now キー）で現在のターン処理を割り込んでキュー中のメッセージをすぐ送信できるようになり、長い routine 途中での方向修正が楽になった。 メモリファイルの age notes がプロンプトキャッシュミスを起こしていたバグも修正済み。

🟢 効率厨の一言: skills sync は claude.ai 側のスキル設定がそのままルーティンエージェントに降りてくるので、複数 routine を回している構成で設定管理が一本化される。npm update -g @anthropic-ai/claude-code 即更新推奨。
→ github.com/anthropics/claude-code/releases/tag/v2.1.275

Claude Code v2.1.274 2026-09-17 00:12 UTC

クリティカルメモリ使用量に近づくと可視の警告が出るようになった（長時間 routine の安定性向上）。 MCP 起動タイミングを調整できる環境変数 CLAUDE_CODE_MCP_STARTUP_WAIT_MS が追加された。 破損したトランスクリプトが自己修復されるようになり、セッション崩壊からの回復が自動化。 レガシー HTTP+SSE プロトコルの MCP サーバー接続改善、/goal コンパクション後の状態保持修正も含む。

🟢 効率厨の一言: トランスクリプト自己修復は夜間 routine でセッションが壊れた時の損失を防ぐ直接の改善。CLAUDE_CODE_MCP_STARTUP_WAIT_MS は MCP 起動失敗に悩んでいるなら即試す価値あり。同じく npm update で反映。
→ github.com/anthropics/claude-code/releases/tag/v2.1.274
