claude-mem — Claude Codeのセッション間メモリを永続化するTypeScriptツール OSS / TypeScript / 95.6k stars / GitHub Trending

Claude Code のセッションが終了・再起動しても「前のセッションで話したこと・決めたこと」を自動で引き継ぎ続けるメモリ永続化レイヤー。セッション終了時にコンテキストをスナップショット化し、次の起動時に自動ロードする。masatoman が現在 CLAUDE.md + ~/.claude/projects/.../memory/MEMORY.md で手動管理している「セッション引き継ぎ」の一部を自動化できる可能性がある。

🟢 効率厨判定: 毎回セッション冒頭で「前回の続きはこのメモリを読んでください」と指示する手間が省ける。まず npx claude-mem init でセットアップして、一日の routine 終了時にスナップショットが正しく保存されるか確認する。既存の MEMORY.md と競合しないかの検証は必要だが、試すコストは低い。

https://github.com/thedotmack/claude-mem
