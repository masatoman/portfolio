v2.1.318 で3つの実用変更が入った。① Agent SDK の hook コールバックに onFailure: "block" オプション追加 — ツール呼び出し失敗時にエージェントをその場で停止できる（今まで失敗を無視して暴走するケースへの直接対策）。② /schedule で予期しないコネクタがアタッチされた場合の警告表示 — このルーティン（tooling-update-watch）が Supabase や Gmail MCP を意図せず呼ぶ際に気づける。③ web/shell ツール呼び出しがアカウントメールをネットワーク送信する前に確認プロンプトを表示。また IDE 拡張がClaude Code 起動時に自動インストール/更新されなくなった（v2.1.318）。Opus 4.8 の Fast モードは 2026-10-30 に廃止予告済・2026-11-30 に削除予定（移行先: Opus 5.5）。
