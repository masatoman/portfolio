Claude Code v2.1.319 (2026-11-06) — denyInsteadOfPrompting + autoMode変更 + /usage + 90件バグ修正
今週最大のリリース。実運用に直結する変更が3つ。

① permissions.denyInsteadOfPrompting — settings.json に追加するだけで、権限確認が必要なツール呼び出しを「確認待ち」ではなく「即拒否してターン続行」に変更できる。無人のスケジュールタスクやルーティンでプロンプト待ちのままハングする問題を直接解消できる。

② autoMode変更（要確認） — テレメトリや CLAUDE_CODE_DISABLE_FEATURE_FLAGS がオフの環境では、サーバー側で確認できない呼び出しが組み込み分類器にフォールバックせず拒否になった。スケジュールタスクや Bedrock/Vertex 以外の環境で auto mode を使っている場合は CLAUDE_CODE_AUTO_MODE_SERVER=0 を環境変数に設定して旧動作に戻す。

③ /usage に今日・今週・今月の利用額表示 — MAX プランの日次チェックに使える。Claude apps gateway 環境では gateway バージョン 2.1.319 以上が条件。

その他: MCPタスクのバックグラウンド化（ターミナル）、/claude-api latency-optimize コマンド（API コードの待ち時間検出）、/tasks に終了済みサブエージェント一覧表示、90件のバグ修正（Bash権限迂回・MCP接続・セッション再開など）。
🟢 即使う 今日やること: ① settings.json に "denyInsteadOfPrompting": true を追加してルーティンのハング防止。② このルーティン自体が auto mode を使っているか確認し、必要なら CLAUDE_CODE_AUTO_MODE_SERVER=0 を設定。③ /usage で今週の利用額を確認。
