Claude Code v2.1.300 リリース — idle compaction で長セッションのキャッシュ切れ防止Anthropic / v2.1.300 / Oct 14, 2026

Claude Code v2.1.300 が Oct 14 にリリース。昨日（10/15）のフィードは v2.1.296 が最新と誤報したため本日訂正。主な変更: (1) idle compaction: 200K+ トークンの会話を 54 分放置すると、1 時間のプロンプトキャッシュが切れる前に自動でコンテキスト圧縮が走る。(2) /advisor コマンド: AWS 上の Claude Platform で利用可能に。(3) OpenTelemetry GenAI 属性追加: OTEL トレーシングを使っている場合に詳細な生成 AI 属性が記録される。(4) Mods 向け API・フック追加、Claude Tag（Claude in Slack）機能拡張。

🟢 効率厨判定: update は自動適用済み（claudeコマンドが最新版を自動取得）。特に作業不要。アイドル 54 分の compaction タイミングを把握した上で、長いルーティンを設計する際の参考にする。OTEL を使うなら GenAI 属性の変化も確認。
