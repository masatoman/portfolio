Claude Code v2.1.234 — CLAUDE_CODE_PROJECT_DIR_NAME + 上限リセット後の自動継続

2026-08-17 20:20 リリース（前日 feed 未掲載）。CLAUDE_CODE_PROJECT_DIR_NAME 環境変数を設定すると、プロジェクトごとのトランスクリプトディレクトリ名をカスタマイズできる。portfolio と 個人開発マネタイズプラットフォーム を並行運用する masatoman は、CLAUDE_CODE_PROJECT_DIR_NAME=komuten のように設定するとトランスクリプトが整理される。

claude.ai 使用上限リセット後に自動でセッションを継続する機能も追加。routine エージェントが上限に引っかかっても再起動不要で復帰する。セキュリティ: Windows NT-namespace パスを悪用した NTLM 資格情報リーク防止の強化も含む。

🟢 即使う — 上限リセット後の自動継続は routine 運用の中断ゼロに直結。CLAUDE_CODE_PROJECT_DIR_NAME は .env または ~/.profile に 1 行追加するだけ。
