Claude Code v2.1.331 — MCP30分ハング修正・VS Code「競合解消」・cloud session再試行 要: claude update
2026-11-23リリース (Latest)。自動化スクリプトと VS Code 開発フローに直接効く主な変更:
  • MCP tool call ハング修正: 一部の malformed レスポンスで最大30分ハングしていたバグを修正。MCP連携ルーティンの安定性が大幅改善。
  • cloud session 再試行: Claude が思考中に応答が止まった場合、自動で1回再試行するように。長時間ルーティン（tooling-update-watch 等）のタイムアウト失敗が減る。
  • VS Code 新機能: 「Fix with Claude Code」クイック修正・「Resolve Merge Conflicts」がVS Codeから直接使える。
  • claude doctor 強化: API 疎通チェックセクションが追加。接続不良のデバッグがコマンド1本で完結。
  • Code Mode 拡張: Amazon Bedrock・Google Cloud Agent Platform・Microsoft Foundry のターミナルセッションでも使えるように。
  • /rewind バグ修正: 失敗したリストア後にファイルが削除されるバグを修正。memory 編集時の信頼性向上。
→ claude update で即アップデート。MCP ハング修正は tooling-update-watch ルーティンや portfolio の自動化スクリプトに直接効く（ローカルMCPサーバーへの接続が詰まって止まるケースを防ぐ）。VS Code 「Resolve Merge Conflicts」は PR レビュー時の手作業を Claude Code に委譲できる。claude doctor の API チェックは次回 Supabase / Vercel MCP 疎通確認時に使う。
