Claude Code v2.1.243 (Aug 24, 23:40 UTC) — 実用改善4点セット
昨日深夜リリース。バグ修正系の v2.1.241 から打って変わって機能追加多め。efficiencyに直接刺さる変更が揃った。
  • /usage にループ内訳追加 — ループごとの実行回数・総トークン・1回あたりトークン・最終実行時刻が見えるようになった
  • modelPicker 設定 — /model ピッカーに表示するモデルを順番・ラベル付きで絞り込める設定が追加
  • promptCacheTtl / subagentPromptCacheTtl 設定 — プロンプトキャッシュ持続時間を明示制御できるように
  • バイナリサイズ大幅縮小 — Linux x64 で 340MB → 75MB (zstd 圧縮)、メモリ使用量も 40-70MB 削減
  • Consoleアカウントでのキーレスサインイン対応
  • Sonnet 5 料金を $2/$10 per Mtok の標準レートに更新
🟢 即使う — /usage のループ内訳で routine の token 消費ホットスポットを特定できる。modelPicker で頻用モデルを 2-3 本に絞ると /model の選択ミスがなくなる。バイナリ縮小は自動適用なので意識不要。
