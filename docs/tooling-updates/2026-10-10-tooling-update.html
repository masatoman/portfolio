Claude Code v2.1.296 (Oct 9) — CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL + autoCompactWindow + Read allow_large Claude Code / v2.1.296 / 2026-10-09

ワークフロー全エージェントを単一モデルで走らせる CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL 環境変数が追加。Workflow スクリプト内で各 agent() 呼び出しに個別の model 指定をしなくても、一つの env で全サブエージェントを Opus 5.5 に固定できる。autoCompactWindow はサブエージェントのフロントマターや --agents 定義に追加でき、コンテキスト自動圧縮のウィンドウをサブエージェント単位でコントロール可能に。

Read ツールに allow_large: true オプション追加。通常のサイズ制限を超えるテキストファイルを 1 回の呼び出しで読める。MCP ツール説明文の上限が 2,048 → 4,096 文字に拡大（説明が長い MCP サーバーで過去に起きた切り詰めが解消される）。Sonnet 5.5 のキャッシュ読み出しが $0.10/M（旧 $0.20）に値下げ（MAX 定額には直接影響なし、知識として）。

🟢 効率厨判定: CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL=claude-opus-5-5 を .env に 1 行追加するだけで Workflow スクリプト全エージェントを Opus 5.5 に統一できる。今日やること → tooling-update-watch と content-executor の Workflow を使う環境に env 変数を追加する。

Claude Code v2.1.295 (Oct 8) — フック onFailure: "block" + $.ui.notify for Mods Claude Code / v2.1.295 / 2026-10-08

コマンド・HTTP フックに onFailure: "block" が追加。フックの起動失敗・タイムアウト・予期せぬ終了が発生した際にアクション全体をブロックする。従来はフック失敗がサイレントにスルーされる可能性があったが、これで「フックが生きている時だけアクションを通す」安全弁を設計できる。

Mods に $.ui.notify が追加され、モッドからデスクトップ通知を発火できるようになった。OSC 7501（Program Status Protocol）サポートも追加、対応ターミナルが Claude の「作業中 / 待機中 / 完了」状態をステータスバーに表示できる。CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS で 429/529 エラー時のリトライ最大待機時間をキャップできる。

🟢 効率厨判定: settings.json の重要フックに onFailure: "block" を付けることで、フック無効時の誤動作を防止できる。特に PreToolUse でコマンド制御しているフックに今日追加する価値あり。

Claude Code v2.1.294 (Oct 8) — prompt/agent フック指示バグ修正 + Stop/SubagentStop 暴発修正 Claude Code / v2.1.294 / 2026-10-08

prompt フックおよび agent フックが「指示」として書かれている場合に、ブロックすべきアクションを通してしまうバグが修正された。これはフックをインストラクション形式で書いている場合に想定外の動作を引き起こしていた可能性がある。

Stop / SubagentStop の prompt フック判定が改善され、Claude がセッションを早期終了しにくくなった。スケジュールルーティン（tooling-update-watch 等）でサブエージェントが途中で止まる問題が解消される可能性がある。
