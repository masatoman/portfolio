Claude Code Artifact: Live MCP コネクターデータ対応 ── Artifact がビューごとに最新データを取得（Week 29 リリース、本フィード初掲載）

Claude Code Week 29 (2026-07-13〜17) リリースで追加された機能。 公開済み Artifact がビューワーに表示されるたびに MCP コネクターを呼び出し、最新データを取得・表示できるようになった。 従来の Artifact はセッション時点のスナップショットだったが、この機能によりダッシュボード的な「ライブ更新ページ」が作れる。 各呼び出しはビューワー自身のコネクター接続を使い、初回アクセス時に承認を求める設計。

masatoman のユースケースに直結する使い方が 2 つある。 (1) GSC 自動化 Artifact のライブ化 — 現在の GSC データ取得 routine は HTML ファイルや Markdown にスナップショットを書き出しているが、 代わりに MCP コネクター対応 Artifact にすると、開くたびに当日最新の検索クリック数・表示回数が表示される自走ダッシュボードになる。 (2) Supabase content_briefs モニター — planned/in_progress のブリーフ件数を Supabase MCP 経由で Artifact から直接参照でき、 Claude Code セッションを起動しなくても状況確認できる。 ただし制約あり: MCP コネクター対応 Artifact はパブリックリンク共有不可（Pro/MAX では作者本人のみ閲覧、Team/Enterprise では組織内共有まで）。 個人利用なら制約に引っかかる場面はほぼない。

🟢 即使う — GSC routine の出力先を snapshot ファイルから Live MCP Artifact に切り替えるだけで「毎朝開くだけのライブダッシュボード」が完成する。artifact-capabilities skill を読んでから実装すること。 → code.claude.com/docs/en/whats-new/2026-w29 → AlternativeTo 解説記事

obra/superpowers — Claude Code・Cursor・Copilot CLI 対応アジェンティックスキルフレームワーク（GitHub Trending #7・261,089★・+479★ 今日）

Jesse Vincent (Prime Radiant) が公開するアジェンティックスキルフレームワーク兼ソフトウェア開発方法論。 Claude Code / Cursor / Codex / GitHub Copilot CLI / Gemini CLI など主要コーディングエージェント全般に対応しており、 特定エージェント専用ではなくエージェント横断で使えるスキル設計が特徴。 リポジトリ構成は skills/（スキル定義）・.agents/plugins/（エージェント別設定）・docs/superpowers/（方法論）の 3 層。

masatoman はすでに ~/.claude/ に独自スキルを運用中だが、 このフレームワークはスキルの「設計方法論」まで含んでいる点が昨日カバーした mattpocock/skills との違い。 mattpocock は「実際に使っているスキルの公開」、superpowers は「スキルをどう設計・組み合わせるかの方法論 + サンプル」という位置づけ。 AGENTS.md に方法論が書かれており、skills/using-superpowers/ に使い方のチュートリアルがある。 Claude Code に直接インポートするなら skills/ 配下のファイルを ~/.claude/ にコピーするだけで動く。

🟢 即使う — repo を clone して AGENTS.md と skills/ を 10-15 分スキャン。masatoman の skill-creator で作ったスキルと設計思想を比較し、足りていない軸（メモリ管理・ループ制御・マルチエージェント連携）があれば参照してリファクタリングできる。 → github.com/obra/superpowers
