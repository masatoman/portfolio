Claude Code Week 29 (v2.1.207〜) — worktree 隔離バグ修正 + 経過時間カウンター (7/13-16)

今週の Claude Code は実害のある バグ修正が 2 本: ① worktree 隔離バグ — worktree 内のサブエージェントがメイン repo に対して git ミューティングコマンドを実行できてしまう問題が修正された。 ② ultracode キーワード誤作動 — Webhook ペイロードや PR コメントのリレーなど非人間入力でも ultracode が発火してしまうバグを修正。

改善点: ツール呼び出しの折りたたみ行にリアルタイム経過時間カウンターが追加され、長時間のツール呼び出しが「止まって見える」問題が解消。 Write(path)・NotebookEdit(path)・Glob(path) の permission ルールに Edit(path)・Read(path) を使うよう起動時に警告が出るようにもなった。

🟢 今すぐ更新 — worktree サブエージェントを並列で走らせている masatoman には worktree 隔離バグは直撃する問題。claude update を今週中に実行。経過時間カウンターで「どのツール呼び出しがボトルネックか」が目視できるようになるのも日常のデバッグ体験が上がる。
