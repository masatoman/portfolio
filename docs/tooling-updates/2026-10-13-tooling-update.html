Anthropic 2026 Usage Policy 改訂 — 自律エージェントの物理制御に新要件追加・11/12 発効 Anthropic / Oct 8, 2026 / 発効 Nov 12

Anthropic が 2026 年の利用ポリシー改訂を発表（発効 2026-11-12）。開発者向けの主要変更点: (1) 物理ハードウェアを自律制御する Claude に「適格オペレーターが機器を停止できること」「Claude 切断時に安全状態を維持できること」の要件を追加。(2) 高リスク推奨事項（AI が医療・法律・金融等の推奨をする場面）の一覧が明示化 — 対象場面には人間のレビューと「AI を使用した」の開示が必要。(3) 兵器条項が「兵器のソフトウェアコンポーネント」「自律車両の武装化」まで拡張。

masatoman の現在のツール（工務店向け Web ツール群・スケジュールルーティン）は Web ベースで物理機器を制御しない。高リスク推奨事項の定義も現行の B2B ツール（日報・写真管理・現場記録）には該当しない可能性が高い。ただし将来の軸 B プロダクトが「工期判断」「安全判断」「施工不良の指摘」等の推奨機能を持つ場合は高リスク推奨事項の対象になりうるため、公式テキストを 1 回確認しておく価値がある。発効まで 30 日ある。

🟡 効率厨判定: 現在のツールには直撃しないが、11/12 発効前に公式テキストを 5 分確認して「高リスク推奨事項の一覧に現行・計画中ツールが入るか」を確認する。特に軸 B MVP が「現場の安全・品質判断を支援する」機能を持つ予定があるなら今のうちに判断基準を固めておく。

Anthropic Cyber Mission — 重要インフラ向け OSS セキュリティスキャン無料提供・開始 Anthropic / Oct 8, 2026 / 無料ベータ

Anthropic が Cyber Mission として (1) 重要インフラ向け Critical Infrastructure Defense Program (CIDP) と (2) オープンソースプロジェクト向け無料 AI 脆弱性スキャンサービスを開始。OSS スキャンは登録プロジェクトに対し Anthropic 最高性能モデルで定期スキャンを実施、各レポートに PoC と修正提案を付けて送付する設計（誤検知率 10% 未満を目標）。提携パートナーは Accenture・Palo Alto Networks・CrowdStrike 等 11 社。

masatoman の portfolio は Next.js + Supabase + Vercel スタック。パブリック OSS リポジトリとして登録すれば無料でスキャンを受けられる可能性がある。ただし CIDP の主な対象は電力・水道・交通・政府システムであり、商用 B2B ツールの Web リポジトリが対象に含まれるかは現時点不明。OSS Scanner の登録フローと対象範囲を公式ページで確認してから判断する必要がある。

🟡 効率厨判定: 商用 B2B リポジトリが対象に入るかを公式フォームで確認。入るなら 5 分で登録して定期セキュリティレポートを無料取得できる。入らないなら ignore。Anthropic が「セキュリティ企業と組んだ」という市場動向として把握しておく価値はある。

Alishahryar1/free-claude-code — Claude Code を「無料」で使えると謳う非公式プロキシ 非公式 OSS / Python / ★59,088 / GitHub Trending +626

61 種の無料 API プロバイダ（NVIDIA NIM 等）を経由して Claude Code のリクエストをルーティングし、月 13 億トークン無料で使えると謳う非公式プロキシ。ローカルで動作し、Claude Code の /model で切り替えて使う設計。ライセンスは AGPL-3.0。「Anthropic 非公認・無関係」と自ら明記している。

masatoman は Claude Code MAX 定額（月額固定）で運用中のため、「無料プロバイダへの切り替え」はコスト削減にならない。むしろ (1) NVIDIA NIM 等の無料枠は変更・廃止リスクがあり運用が不安定になる、(2) Claude のモデル品質ではなく他プロバイダの劣化版モデルで動くため効率が落ちる、(3) 商用利用時に各プロバイダの ToS 違反リスクが生じる、(4) AGPL ライセンスなので組み込む場合は商用コードまで GPL 汚染される、という問題がある。626 stars/day で trending しているが、内容はコスト悩みの初心者向けで masatoman には不要。

🚫 効率厨判定: MAX 定額ユーザーがこれを入れても何も得しない。モデル品質が落ちてルーティンが壊れるリスクの方が大きい。trending しているからといって試さない。現スタックで完結。
