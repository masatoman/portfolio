Claude Code v2.1.302 — fork subagents がデフォルト有効化、AUTO_MODE_MODEL 追加 2026-10-16

フォーク型サブエージェント（subagent_type: "fork"）がデフォルトで有効になった。今日からルーティンや /loop セッションで fork を指定すると自動的に走り、メイン会話のコンテキスト汚染を防げる。

新環境変数 CLAUDE_CODE_AUTO_MODE_MODEL で、クライアント側の auto mode 分類器が使うモデルを個別指定できるようになった。重いモデルで分類させたいシーンでピンポイント設定可能。また git 2.56 以降で worktree 作成が壊れていたバグが修正済み——worktree 分離で並列作業する人はアップデート必須。

⚠️ Claude Design 終了告知: /design-sync / /design-login コマンドで 2026-12-14 に claude.ai/design（スタンドアロン版）が終了する旨が表示されるようになった。使っている場合は移行計画を今から立てること。

🟢 即使う — MAX プランのルーティン + /loop を使っているなら fork のデフォルト有効がすぐ効く。git 2.56 worktree バグ修正も実運用で地味に重要。

Claude Code v2.1.301 — Vim % キー追加、mod に multiline inputs、OpenTelemetry 拡張 2026-10-15

Vim モードに %（対応する括弧へジャンプ、d/c/y と組み合わせ可）が追加。Vim ユーザーはコード内の括弧操作が今日からフル Vim 体験になる。

mod の Input に rows フィールドが追加され、複数行テキスト欄が作れるようになった。自作プラグインやフォーム型 mod を書いている場合は使えるアップデート。OpenTelemetry に classifier_verdict / permission_mode / classifier_category が追加され、自動化パイプラインでどの判断がブロックされているかをログで追跡できる。

🟢 即使う — Vim ユーザーと mod 作成者に直接刺さる。OpenTelemetry 拡張は自動化の詰まりポイント可視化に今すぐ活用可。
