Vercel eve 1.0 GA — "Next.js for agents" 本番向け OSS エージェントフレームワーク
Vercel が 2026/06 の Ship カンファレンスで発表し、今月 1.0 GA になったオープンソースフレームワーク（Apache 2.0）。エージェントをディレクトリ構造で定義し、ローカルまたは Vercel 上でデプロイできる。実行は durable workflow（クラッシュ後に自動再開）、isolated sandbox 実行、Human-in-the-loop 承認ゲートをネイティブサポート。
  • OSS 本体（eve + Workflow SDK）は Apache 2.0 無料。Vercel 上の Workflow 実行・Sandbox 利用は Vercel 課金に乗る。
  • 競合は Mastra（マルチプラットフォーム向け）。eve は Vercel 最適化。
  • docs は「Beta」表記が残っており、GA の正式なタイミングは一次確認推奨。
