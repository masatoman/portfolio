昨日カバーした v2.1.287 の直後リリース。主な変更点: (1) $.ui.selection() API 追加 — Mod からユーザーに「選択肢を提示してひとつ選ばせる」インタラクティブな UI を呼び出せるようになった。既存の $.ui.confirm() / $.ui.input() に加わる 3 本目の対話 API。Mod で「今日のフィードはどの件数まで詳細を書くか」を聞くようなステップを組み込める。(2) 複数の安定化バグ修正が含まれているが、v2.1.287 の rm セーフガード修正ほどのクリティカル度合いはない。
