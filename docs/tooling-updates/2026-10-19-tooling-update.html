akitaonrails/ai-memory — エージェント間のコンテキストを引き継ぐローカル MCP サーバー GitHub Trending ★10.5k +512/day · Rust · MIT

Rust 製のシングルバイナリ MCP/HTTP サーバー。Claude Code・Codex・Cursor・Gemini CLI など複数のエージェント CLI のライフサイクルフックに割り込み、セッション活動を git バージョン管理された Markdown ウィキとして自動記録する。別のエージェントへ切り替える際に「どこまでやったか」サマリが自動で先頭に挿入される。ストレージは SQLite + FTS5 全文検索（オプションでベクター埋め込み）。
