Claude Code v2.1.332 — MCP Skills Beta + PreSkillShellCommand hook + freeze 大量修正
2026-11-25 リリース。主な変更点:
  • MCP Skills Beta: MCP サーバーが提供するスキルが / メニューに server:skill 形式で表示される。stitch-skills 等を入れているなら今日から見える。
  • PreSkillShellCommand hook: スキル読み込み時の inline shell command を hook で事前フィルタリング可能に。.claude/settings.json に追加するだけ。
  • freeze 大量修正: hook 大量出力（約 50,000 文字超で自動短縮）・named pipe（20秒でタイムアウト）・MCP server stdout flood・minified CSS の @mention フリーズ を全修正。scheduled routine の安定運用に直結。
  • Task ID 重複バグ修正: TaskCreate/TaskGet で ID が重複する・削除済みタスクが復活する・完了タスクがブロッカー扱いされる問題を修正。
  • Grep 修正: -o の末尾空一致ミス・multiline での行番号ズレ・-A/-B が -C=0 併用時に無視される問題を修正。日次フィードの検索系コマンドが今日から正確に動く。
  • MCP task ID 1,024文字対応: 従来 128文字制限で失敗していた MCP ツール呼び出しが通るようになる。
  • auth 修正: claude auth login が失敗時に「Login successful.」と誤報せず、exit 1 + ヒントを返す。
→ claude update で即適用。フリーズ修正だけでも今日やる価値あり。MCP Skills Beta は / メニューを開いて server:skill が出るか確認するだけ。PreSkillShellCommand hook は CLAUDE.md や settings.json のカスタム hook 設計に今すぐ組み込める。
