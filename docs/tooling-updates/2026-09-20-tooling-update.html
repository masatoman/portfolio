Claude Code v2.1.278 — auto mode サーバーサイドクラシファイア化 2026-09-19 03:10 UTC

Claude API・Enterprise ユーザーに対して auto mode がデフォルトでサーバーサイドクラシファイアを使うようになった。 これまでの「クラシファイアオーバーヘッド課金」が解消される変更で、Bedrock / Vertex / Foundry / ゲートウェイ経由の場合はオプトアウト変数 CLAUDE_CODE_AUTO_MODE_SERVER=0 で旧挙動に戻せる。 /status に "Auto mode server" 行が追加されたので自環境の確認が即できる。 この scheduled routine 自体も cloud/Enterprise 環境で動いており、今バージョンで挙動が変わる可能性がある。

🟢 効率厨の一言: npm update -g @anthropic-ai/claude-code で即更新。/status で "Auto mode server" 行を確認し、scheduler/routine の auto mode 挙動が変わっていないかチェック。Bedrock/Vertex 経由の routine があれば CLAUDE_CODE_AUTO_MODE_SERVER=0 の要否も確認。

cactus-compute/needle 3 — 9MB オンデバイス tool-calling モデル 2026-09-19 launch / GitHub Trending #9

YC S25 スタートアップ Cactus Compute が needle 3 をリリース。 わずか 9MB の量子化モデルで、スマートフォン・ウェアラブル・マイコンなどリソース制約デバイス上でツール呼び出しと構造化データ抽出を実行できる。 「リビングルームの照明を 30% にして」→ 対応関数＋パラメータを推定、という用途に特化した設計。 Laddered Simple Attention Network アーキテクチャで深さ 2〜20 層が全てデプロイ可能モデルになっている。
