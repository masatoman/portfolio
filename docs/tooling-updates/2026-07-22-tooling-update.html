Claude Code v2.1.217 — サブエージェント上限制御・MCP メモリリーク修正 (2026-07-21 21:35 UTC)

tooling-update-watch（本エージェント）や morning-brief など並列サブエージェントを使う routine では、予期しない過剰並列やトークン超過が起きた際の制御弁が増えたことになる。 加えて「切り詰められた MCP ツール出力によるメモリリーク」も修正。長期セッションでの MCP 連携が徐々に重くなっていた原因候補が潰された。

その他: PR バッジのフッターリンクがクリッカブルになった（GitHub MCP 連携後の PR 確認がスムーズになる）、Windows 自動更新の claude.exe 消失バグ修正、法人 mTLS・プロキシ設定が Desktop セッションでも反映されるよう改善。
