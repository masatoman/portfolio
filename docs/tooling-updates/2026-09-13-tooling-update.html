Claude Code v2.1.270 (2026-09-12) — 長時間セッションで読み取り専用 git コマンドが許可を求める regression 修正

v2.1.269 で混入した regression がホットフィックス。セッションを長時間動かし続けると git status や git log など読み取り専用の git コマンドまで 許可プロンプトを求めるようになっていた問題が修正された。

あわせて以下も修正: (1) セッション途中でモデルがサイレントに別モデルへ切り替わる問題、 (2) 端末プロトコル処理の複数の互換バグ、(3) サードパーティエンドポイントへの HTTP 400 エラー、 (4) WebFetch が無期限にハングする問題。

この feed を含むスケジュールルーティンは長時間セッションになりやすいため、 git status 確認ステップで毎回許可プロンプトが出ていた場合はこのバージョンで解消される。

GitHub Copilot 並列エージェントセッション — 複数タスクを独立 worktree で同時実行

GitHub Copilot アプリが並列エージェントセッションに対応。 複数の AI タスクが独立した Git worktree と独自コンテキストを持ち、 並行して実行できるようになった。長時間の開発セッションで 他タスクをブロックせず作業できる点が売り。
