Claude Code v2.1.265 + v2.1.266 (2026-09-08) — メジャーアップデート

🟢 即使う

v2.1.265 は大型リリース。v2.1.266 は翌日の緊急パッチ（LLM-gateway 回帰修正）。

  • --plugin-dir にフォルダ指定が可能に: マニフェストを持つ子フォルダを自動ロード。複数プラグインを1フォルダにまとめてポイントするだけ。スキル/プラグイン整理の手間が減る。
  • セッション自動アーカイブ: VSCode サイドバーの "Archive inactive sessions" がデフォルト 14日 で有効化。放置セッションが自動で整理され、サイドバー汚染がなくなる。
  • ツール結果の 1GB 上限 + 通知: ディスク保存が巨大になった際に truncation 通知。長大な Bash 出力が無言で消えるバグを防ぐ。
  • 2キーショートカットのタイムアウトを 3秒 に延長（旧 1秒）: 誤作動が減る。
  • サブエージェント再開バグ修正: フォアグラウンド起動のサブエージェントを resume したときにツールリスト・システムプロンプトが変わり prompt-cache が壊れていた問題を修正。routine / schedule 型エージェントを多用する masatoman に直撃する修正。
  • /model opusplan[1m] が通るように: "Model not found" エラー解消。
