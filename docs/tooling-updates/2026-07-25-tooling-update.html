Claude Code v2.1.219 — Claude Opus 5 デフォルト化・サブエージェント深度3・DirectoryAdded hook (2026-07-24)

前日 2026-07-24 17:14 UTC リリース。Claude Opus 5 (claude-opus-5) が Opus のデフォルトモデルに昇格。 コンテキスト 1M トークン、fast mode 対応 ($10/$50 per Mtok)。MAX プラン定額ユーザーは追加課金なく即日利用開始。 Anthropic は同日「Introducing Claude Opus 5」記事も公開 — Fable 5 に次ぐ frontier 水準を半額で、と表現している。

ワークフロー設計で使える変更が 3 つ: (1) サブエージェントのネスト深度がデフォルト 3 に拡大（旧: 1）。 Workflow スクリプト内でサブエージェントが孫エージェントを呼べるようになり、 pipeline → 検証サブエージェント → さらに詳細調査、という 3 段構成が設定変更なしで使える。 (2) workflowSizeGuideline 設定キー追加 — プロジェクト設定で Dynamic workflow の推奨サイズ（medium = 15 エージェント以下）を上書きできる。 (3) DirectoryAdded hook 追加 — /add-dir や SDK の register_repo_root で新しい作業ディレクトリが登録された瞬間に hook が発火。 複数 repo を動的に追加する routine の後処理（自動 ls / CLAUDE.md 読み込み確認）が書けるようになる。

その他: sandbox.network.strictAllowlist でホワイトリスト外ホストへのサンドボックス通信を プロンプトなしで即ブロック可能。/fast は Opus 4.7 が除外され、Opus 5 と Opus 4.8 に絞られた。

🟢 即使う — MAX プランで Opus 5 はすでに有効。サブエージェント深度 3 は今日の Workflow スクリプトから即使える。DirectoryAdded hook は multi-repo routine を書く際に参照。 → github.com/anthropics/claude-code/releases (v2.1.219) → anthropic.com/news/claude-opus-5
