🟡 様子見 LangChain 公式リリース langchain-ai/openwiki — git差分を読んでコードベースの wiki を自動更新する CLI（GitHub Actions 対応）

LangChain が公開した TypeScript 製 CLI。openwiki init で初回 wiki を生成、openwiki update で 「前回 run からのコミット差分」を読んで wiki を自動更新。 GitHub Actions でスケジュール実行すれば、コードが変わるたびに openwiki/ フォルダのドキュメントが追従する。 モデルプロバイダは Anthropic / OpenAI / OpenRouter などを選択可。

効率厨の一言（即使えない理由）： MAX プラン定額で動かすには Anthropic API キーが別途必要（Claude Code を経由しない直叩き）。 portfolio の CLAUDE.md は戦略・フォーマット・記憶体系が密結合しており、 自動生成ドキュメントがそこに割り込むと混乱する可能性がある。 将来の SaaS MVP など新規コードベースで試すのが現実的。 API 直叩きコスト管理の準備ができた段階で再評価。
