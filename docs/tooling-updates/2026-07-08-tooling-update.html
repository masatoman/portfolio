🟢 即使う Claude Code Releases Claude Code v2.1.203 — macOS 背景エージェント 15-20 秒遅延修正 + ログイン有効期限切れ前警告 + バイナリ -7MB

v2.1.202（07-06）の次のリリース。masatoman の運用に直接刺さる変更点:

  • macOS で背景エージェントセッション起動時の 15-20 秒遅延を修正。 このフィードエージェントを含む全 routine が朝起動するたびに 15-20 秒かかっていたなら、今日から解消される。
  • 背景セッションがデーモンのセッショントークン失効時に無応答になる問題を修正。 夜間ルーティンや長時間バックグラウンド実行が途中で止まる原因がこれだった可能性がある。
  • ログイン有効期限切れ前に警告を表示するようになった。 突然ログアウトされてルーティンが失敗するケースへの保険。
  • マニュアルパーミッションモード時にフッターに一時停止バッジを表示。 意図せずマニュアルモードになっていることに気づきやすくなる。
  • バイナリサイズ・起動メモリをそれぞれ約 7MB 削減。スタート速度が上がる。
  • その他: MCP roots/list にセッションの追加作業ディレクトリを追加 / git worktree 多数時の Bash 引数リスト問題修正 / Windows 用バックグラウンドタスク出力修正
今日やること: claude update で v2.1.203 に更新。 背景エージェント遅延と token 失効無応答の両方が直っているので、 長時間 routine（このフィード含む）の信頼性が上がる。

MAX プランの masatoman がやること:
