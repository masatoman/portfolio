VS Code 1.137 2026-09-10 リリース / 今週初出 — Automations (Preview) + Agent Host Protocol

9/10 リリースで今フィード初登場。主な追加:

① Automations (Preview): エージェントタスクを hourly / daily / weekly でスケジュール実行、またはオンデマンド起動できる。 Claude Code の /loop + routine と役割が重なるが、VS Code のワークスペースに紐付けた形で動かせる点が違う。

② Agent Host Protocol: AI セッションをワークスペース（フォルダ）から切り離し、SSH リモートで動かせるオープンプロトコル。 複数マシン・複数プロジェクトをエージェントで横断したい場面で本命になる。

③ Voice Mode（⚠️ 罠注意）: GitHub Copilot 個人プラン必須。Business / Enterprise 不可。 この機能だけのために Copilot を追加契約するコストに見合わない（→ 🚫 セクション参照）。

🟡 効率厨の一言: Claude Code CLI 主体の今の運用では Automations は既存 routine で代替済。Agent Host Protocol は SSH 越しの multi-machine 運用が増えてきた段階で再評価。今は読んでおくだけでよい。
→ code.visualstudio.com/updates/v1_137

VS Code 1.137 Voice Mode Experimental — GitHub Copilot 個人プラン必須・今の構成には不要

VS Code 1.137 で追加された Voice Mode（エージェントと音声で会話 + 割り込み可能）は GitHub Copilot 個人プランが必要で、Business / Enterprise プランでは使用不可。 masatoman は Claude Code MAX プラン定額で運用中のため、 この機能のためだけに Copilot を追加契約しても費用対効果はゼロ。

音声インターフェースが欲しい場面は Claude web UI の会話モードで代替できる。

🚫 効率厨の一言: 「音声でコーディング」の訴求に引っ張られて Copilot を追加課金しない。今の MAX プラン運用と組み合わせるメリットがない。
