Graphify-Labs/graphify — コードベースを知識グラフ化する Claude Code 対応スキル (85k★・GitHub Trending 9位 +1,851 今日)

コード・SQL スキーマ・ドキュメント・画像・動画など、フォルダ内の全ファイルを クエリ可能な知識グラフ に変換する Python 製ツール。 Y Combinator S26 出資。tree-sitter AST で 36 言語のパースをローカル実行 — LLM に送らず、自分のマシン上のグラフファイルとして保存される。

Claude Code・Codex・Cursor・Gemini CLI など主要 AI コーディングアシスタントに対応。 /graphify・/graphify query・/graphify path・/graphify explain の 4 コマンドをセッション内で使える。 出力: graph.html (インタラクティブ可視化)・graph.json (クエリ用)・GRAPH_REPORT.md (監査レポート)。

🟢 今日試す — portfolio の local-business 8 ルートや Skills・Routines が増えてきた今、/graphify でコードマップを生成すれば Claude がファイルをひとつひとつ grep せずに「どこで何が呼ばれているか」をグラフクエリで把握できる。ローカル完結なので CLAUDE.md・STRATEGY.md の機密コンテキストが外部に出ない点も運用に合う。まず npx graphify を portfolio ルートで走らせて graph.html を確認するところから。
