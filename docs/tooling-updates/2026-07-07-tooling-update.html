今日フィード生成後にリリースされた最新版。変更点：

  • /config でワークフローサイズを動的に設定できるようになった。 これまでワークフローの同時エージェント数はコード固定だったが、セッションごとに /config から調整可能になった。 ルーティン側でエージェント数を絞ってコンテキストを節約する・増やして速度優先する、の切り替えが UI から完結する。
  • /review <pr> を single-pass に戻し、マルチエージェントレビューは /code-review スキルへ誘導。 いつの間にか /review がマルチエージェント動作していたバグを修正。 マルチエージェントレビューを使いたい場合は明示的に /code-review を呼ぶこと。
  • その他: inline Ctrl+R 履歴検索クラッシュ修正 / /rename がリバートされるバグ修正 / mTLS ハンドシェイク失敗修正 / Remote Control コマンドが interactive session で失敗するバグ修正 / OpenTelemetry 属性に workflow.run_id / workflow.name 追加
今日やること: ① claude update で v2.1.202 に更新。 ② /config を開いてワークフローサイズ設定を確認（このフィードエージェント自身も Workflow を使うので最適値に調整を）。 ③ /review と /code-review の呼び分けを意識する（ルーティン・スクリプトに /review を書いていた箇所は /code-review に変更）。
