🟢 即使う Claude Code v2.1.319 — denyInsteadOfPrompting + MCPタスクのバックグラウンド実行
11/6 リリース（v2.1.321 以降で動作確認済）。2つの実用変更が入った。①permissions.denyInsteadOfPrompting: true を settings.json に追加すると、未許可操作をプロンプト待ちで止めず即 deny → routine / CI パイプラインが詰まらなくなる。② MCP タスクがバックグラウンド実行になり、完了後に結果を返す形に変更。CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND=1 で旧挙動に戻せる。さらに auto mode で拒否されたアクションが exit code 0 ではなく 1 を返すようになった（claude -p パイプラインの error handling に影響）。
効率厨の一言: tooling-update-watch routine など -p パイプラインを使っている routine は exit code 1 対応を確認。denyInsteadOfPrompting: true はスケジュールタスクの self-healing に直結するので今日 settings.json に追加できる。
