Cursor v3.11 ── Side Chats + Conversation Search + Cloud Agent Hooks

並列エージェント会話 (Side Chats) でメインコンテキストを汚さず別タスクを並走できるようになった。Conversation Search は過去チャットを全文検索。Cloud Agent Hooks はリモートトリガーで Cursor エージェントを起動する仕組み。

Claude Code がメインのスタックなら今すぐ乗り換え理由はないが、Side Chats の設計思想は Claude Code の /fork に近く、比較記事ネタとして使える。

🟡 様子見 ── Claude Code に同等機能があるため今は静観。Cursor vs Claude Code 比較記事で「3.11 時点の差分」として言及すると鮮度が出る。 Cursor vs Claude Code vs Windsurf 2026 比較

Zapier AI Agents ── 7000+ アプリ対応でついに GA

拡張ベータを経て Zapier の AI エージェント層が正式 GA。条件分岐・エラー回復・マルチブランチワークフローに対応し、Zapier の全 7000+ アプリカタログをエージェントが自律実行できる。

tuicr ── Rust 製 TUI コードレビュー (GitHub Trending +335★)

GitHub Copilot SDK ── アプリ内 Copilot 組み込み (Java / マルチプラットフォーム)

GitHub Copilot Agent をサードパーティアプリに組み込むためのマルチプラットフォーム SDK。Java 製で iOS・Android・Web・デスクトップへのネイティブ統合を想定。

🟡 様子見 ── エンタープライズ向け SDK。個人 SaaS に Copilot ブランドが必要になった時点で評価。今は不要。 github.com/github/copilot-sdk
