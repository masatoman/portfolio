Windsurf → Devin Desktop 3.2 — subagentがMCPツールを直接呼び出し対応・Devinプラグインシステムがpreviewに

6月2日に Windsurf から Devin Desktop にリブランドした旧 Cascade ベースの IDE が 3.2 系列アップデートを展開中。 今回の主な追加は3点。 (1) subagentがMCPツールを直接呼び出せるようになった（これまでメインエージェント経由だった）、 (2) Devin Local 向けプラグインシステムが enterprise opt-in のプレビューで開始、 (3) CLI 権限スコープによる terminal allow/deny リストをチームレベルで強制適用できるように。

masatoman は Claude Code メインなので Devin Desktop への乗り換えは不要。 ただし「subagentがMCPツールを直接呼び出す」設計は Claude Code のサブエージェント実装（Workflow tool の agent()）と同方向であり、 競合他社が同機能を標準搭載し始めたことで この設計がAIコーディングIDEのデファクトになる流れを確認できる。 plugin system の仕組みを Devin Desktop → Claude Code スキル設計の参考として読む価値あり。
