Claude Code v2.1.309: bypass-permissions モードで rm/rmdir が即ブロックに変更

2026-10-22 Latest

VS Code 拡張・Desktop アプリの「bypass-permissions モード」で実行された rm/rmdir が、プロンプトなしで即座に拒否され rewrite ヒントを返すよう変更。また、サンドボックス化された Bash がシェル起動ファイル（.bashrc 等）を読まなくなり、サンドボックス内で --mcp-config を書き換えられなくなった。PDF Read の Linux 版ページ範囲バグ、VS Code の Ctrl+J ハンドリングなども修正。

bypass モードで Claude に大量ファイル操作を任せる場面で rm 誤爆が防がれる。「やっておいて」と投げた瞬間に意図しないファイル削除が起きなくなる変更 — 今日の運用からそのまま恩恵を受ける。動作が変わったことを把握しておくべき。

Claude Code v2.1.306: cloud session 内の claude -p で "Not logged in" バグ修正

2026-10-21

cloud session 内で claude -p（print/SDK モード）を実行すると「Not logged in」と表示されて失敗するバグが修正。セッションの環境変数が引き継がれていなかったことが原因。あわせて、MCP ツール数が多いセッションで起きていた「プロンプトが長すぎます」誤表示と不要な compaction も修正。

scheduled routine や hook 経由で claude -p を cloud session 内から呼ぶ場面（このフィード自体がその使い方）で詰まるバグが消えた。スケジュール実行 + Skills + routines の組み合わせで引っかかっていた人はすぐ確認を。
