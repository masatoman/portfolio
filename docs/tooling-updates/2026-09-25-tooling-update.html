Claude Code v2.1.282 — resumed session 改変バグ修正 + maxProseWidth 設定追加 2026-09-24 18:38 UTC

v2.1.281 に続く翌日リリース。主な修正：① resumed/continued session が以前のメッセージを変形して再送信するバグを修正（reasoning が再送時に落ちて API がキャッシュ破棄していた問題）、② slash コマンド（/model / /rename / /artifacts）実行時に extended thinking が消えるバグ修正、③ 400 エラー（web search 結果が復号不能な会話でリクエスト失敗）を修正、④ 中間パターンの :* 権限ルールが特定状況でスキップされるバグを修正。新機能として maxProseWidth 設定（wide terminal での prose 折り返し幅を cap、テーブル・コードは full width 維持）と Chrome managed mode での allowClaudeInChromeWithManagedMcp 設定が追加。

【効率厨verdict】① の resumed session 改変バグは tooling-update-watch など daily routine エージェントが長時間セッションを継続する際に reasoning が消えて精度が落ちる原因だった可能性がある。MAX プランは自動更新なので修正は適用済みのはず。maxProseWidth: 100 等を .claude/settings.json に追加すれば routine レポートの行折り返しが整い可読性が上がる。
