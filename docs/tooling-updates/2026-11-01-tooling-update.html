Claude Code v2.1.316 — CLAUDE_CODE_SUBAGENT_EFFORT でサブエージェントの effort を一括制御
v2.1.316 (2026-10-31) で追加された環境変数 CLAUDE_CODE_SUBAGENT_EFFORT を設定すると、Workflow で起動する worker agent の effort レベルを一括指定できる。同時追加の CLAUDE_CODE_DISABLE_ULTRATHINK は ultrathink キーワードを無効化し、意図しない xhigh effort への昇格を防ぐ。
🟢 即使う tooling-update-watch などのルーティン Workflow で subagent が暴走するリスクを CLAUDE_CODE_SUBAGENT_EFFORT=low で抑えられる。settings.json の env に今日追加できる。コスト管理と再現性の両方に直結。

Claude Code v2.1.314 — permissions.blockWritesOutsideWorkingDirectories で作業ディレクトリ外書き込みブロック
permissions.blockWritesOutsideWorkingDirectories を有効化すると、Write / Edit / NotebookEdit ツールが作業ディレクトリ外への書き込みを全権限モードでも拒否する。エージェントが意図せず ~/ 以下の設定ファイルを変更するリスクを排除できる。
🟢 即使う portfolio リポジトリの CLAUDE.md に "permissions": {"blockWritesOutsideWorkingDirectories": true} を追加するだけで有効。ルーティンエージェントが memory ディレクトリやホームを誤って書き換える事故を防ぐ安全網として今日から設定できる。
