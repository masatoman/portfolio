Claude Code v2.1.271 2026-09-14 — リモートセッション Fast Mode、/config マウス操作、コマンド単位の allowed_domains

Anthropic が 9/14 にリリースした v2.1.271 は、このルーティンエージェントが直接恩恵を受けるアップデートが3点まとまって入った。

① Fast mode がリモートセッションに対応: クラウド実行環境 (= このスケジュール起動) でも組織設定で Fast mode を許可できるようになった。今まで Fast mode はローカル CLI だけだったが、リモートの automated routine でも高速出力が選択肢に入る。

② /config パネルがマウス操作に対応: ホイールスクロール・クリックで値変更・ポインタ強調が効くようになった。設定変更の手間が減る。

③ コマンド単位の allowed_domains: Bash / PowerShell / Monitor ツールの auto+sandbox モードで、コマンド実行ごとにアクセス先ホストをレビューできる。routine agent が想定外の外部ホストに飛ぶのを防ぐ細粒度制御。

その他: omitClaudeMd frontmatter（サブエージェントに CLAUDE.md を読ませない）、Markdown ファイルが Artifact としてスタイル付きページに変換されるようになった点も記事ネタとして使える。

🟢 効率厨の一言: リモートセッション Fast mode は今日の routine 実行から設定確認の価値あり。③ の per-command allowed_domains は routine agent のセキュリティ強化に直結する — 設定に組み込むかどうか /config で確認すべき。
