Claude Code v2.1.283 — /doctor prompt-audit で CLAUDE.md を診断 + startup 高速化 2026-09-25 21:50 UTC

新機能が3点。① /doctor prompt-audit：プロジェクト内の CLAUDE.md ファイルと prompting パターンを旧モデル向けの非効率な書き方がないか監査するコマンドを追加。② モデルバージョン固定設定：availableModelsMatch: "exact" で特定モデルバージョン以外を blocked、deniedModels リストで個別モデルを除外できる managed setting を追加。③ startup 高速化：auto-mode 分類器と Artifact ツールのロードを遅延評価に変更し、初回起動を改善。加えて SDK セッションが turn 早期終了時に deferred tool calls を消失するバグ、vim mode のカーソル位置・キーリピートの多数バグも修正。

【効率厨verdict】/doctor prompt-audit は「今すぐ叩ける」コマンド。portfolio の CLAUDE.md（STRATEGY.md import + 40+ memory インデックス）と Skills ファイル群は Claude 3.5 Sonnet 時代に書かれた記述が混在している可能性がある。今日 $claude /doctor prompt-audit を実行して不要なプロンプトパターンを刈り込むと routine エージェントの精度・コスト効率が改善する。モデル固定設定は Sonnet 4.6 pinning にも使える。
