Claude Code v2.1.269 (2026-09-11) — claude plugin eval 追加・/output-style コマンド・プロンプトキャッシュ修正

claude plugin eval が追加された。スキル（plugin）の eval スイートを Claude Code 上で実行し、JSON + HTML レポートとしてスコアリングできる。 CLAUDE.md + Skills ベースで routine を組んでいる場合、スキルの品質を CI 的に定量評価できるようになった。

/output-style [name] コマンド追加。登録済み output-style を 端末から一覧表示・切替できる。セッションごとに手動でスタイルを切り替える手間が減る。

プロンプトキャッシュが resumed responses で部分的に破棄されるバグを修正。 スケジュールタスク（tooling-feed / GSC 等）が長い会話の途中でキャッシュを再利用 できていなかった場合はこの修正で改善される。

その他: WezTerm / rxvt-unicode / kitty-protocol 等での F1〜F4・特殊キー動作を修正。 バックグラウンドエージェント稼働中に「waiting for your input」と誤表示される問題を修正。 /diff パネルのフルスクリーン応答性を改善。

🟢 効率厨の一言: claude plugin eval は routine agentのスキル品質チェックに今日から組み込める。update するだけで即反映。
