🟢 即使う Claude Code v2.1.310

2026-10-23 リリース。バグ修正が多く、MAXプラン定額で長コンテキスト routineを常用するユーザーに直撃する修正が複数含まれる。

  • 貼り付け画像の消失バグを修正 — cleanupPeriodDays に大きな値を設定していると最近のファイル(pasted imagesを含む)が削除されていた問題が解消。
  • 長文後のcompaction再失敗を修正 — base64/SVGが多いターンで "Prompt is too long" エラーが出た後、次のリクエストも失敗し続けるバグが修正された。
  • rm/rmdir の危険操作を即 deny に変更 — bypass permissionsモード(Desktop/VSCode)でも危険なrm/rmdirは即座に拒否しrewriteヒントを出す。agenticセッションの安全性が上がる。
  • Cloud sessions: Enterpriseカスタムロールに権限追加 — Cloud sessions / Remote Control の権限をロール単位で制御可能に。
  • claudeタグの ! コマンド修正 — Slackで !restart などを太字・斜体で送っても普通のメッセージ扱いされていたバグを修正。
  • その他: symbolic link先の表示修正、MCP タイムアウトエラーメッセージ改善、ゲートウェイ互換性向上 など多数。
効率厨の一言: MAXプランで長コンテキスト sessionをroutineに使うと compactionの再失敗に詰まることがあった。今回の修正で「長文後に次のリクエストが詰まる」が解消される。paste素材が消えるバグも意図せず踏んでいた可能性があるので今日アップデート確定。
