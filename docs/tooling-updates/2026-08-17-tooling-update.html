Revise — AI Document Editor with built-in MCP server (2026-08-11 launch)

ブラウザベースのドキュメントエディタ。AI エージェントが文書の 中 に入って tracked changes（変更履歴つき）で編集できる。DOCX インポート・エクスポート対応、ヘッダー/リスト/表/太字・斜体/画像をフォーマット保持で読み込める。無料プランあり。

特筆点：ビルトイン MCP サーバー搭載。つまり Claude Code から mcp add revise で繋ぐと、Claude Code セッション上から revise.io 内の文書に直接 tracked changes で書き込める。masatoman.net のブログ下書き・北原氏向け提案書・ヒアリング設計 docs の初稿を Claude Code から一発投入して、人間は変更承認だけするワークフローが組める。

今日のアクション: revise.io に無料登録 → Professionals ページで MCP エンドポイントを確認 → Claude Code の ~/.claude/settings.json に mcpServers.revise を追加して動作確認（30分）。

⚠️ Google Imagen 4 API — 本日 2026-08-17 をもって shutdown（3モデル同時終了）

Google が Imagen 4 の安定版エンドポイント 3本（imagen-4.0-generate-001、imagen-4.0-ultra-generate-001、imagen-4.0-fast-generate-001）を本日 2026-08-17 付で廃止。Gemini Developer API・Vertex AI 両方が対象。後継は Gemini 3.x Image モデル（通称「Nano Banana」）だが、drop-in swap ではない——generate_images() メソッドが丸ごと廃止されているため、移行には API 呼び出しの書き直しが必要。

masatoman は現在 Google 画像生成 API を運用していないため直接被害ゼロ。ただし「ベンダー主導の突然の API 廃止」はプラットフォームリスクの典型例——Claude Code (Anthropic) / Supabase / Vercel 依存のスタックでも同様のリスクがある。今後 Google サービスを追加する際は "deprecation timeline" を必ずチェックする習慣を持つ。

🚫 罠（他山の石）— masatoman が Imagen を使っていればデグレ不可避だった事例。新規 API 採用時はベンダーの廃止ポリシーを先に調べる。
