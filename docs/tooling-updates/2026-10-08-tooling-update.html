Claude Code v2.1.293 リリース — MCP/SendMessage バグ修正多数 2026-10-07

HTTP MCPのメモリリーク、バックグラウンド移行時のメッセージ消失、SendMessageの誤動作、claude logs実行時のサインアウト問題をまとめて修正。アイドル時のスキル同期が10分→約40分間隔になり無駄なAPI呼び出しが減少。

Claude Code v2.1.292 — rm -rf セキュリティ修正 + plugin --marketplace 2026-10-06

8.3形式の短いパス（例: C:\PROGRA~1相当）を使ってホームフォルダの保護判定をバイパスし rm -rf を実行できた脆弱性を修正。PreToolUseフックやauto modeでのUNCパス経由ファイル読み取り承認バイパスも同時修正。

claude plugin install --marketplace <source> が追加。マーケットプレイス登録とプラグインインストールを1コマンドで完結できるようになった。

💬 セキュリティ修正なので理由なく先送りしない。plugin --marketplaceは新スキル試す時のコストが下がる。

→ code.claude.com/docs/en/changelog
